# 請求書PDF 自動作成ツール（Google スプレッドシート + GAS）

スプレッドシートに請求の明細を入力し、メニューから実行するだけで、
**請求番号ごとの請求書PDFを作成して Google ドライブに保存**するツールです。

## できること
- 「明細」シートの行を請求番号ごとにまとめ、1件ずつ請求書を作成
- A4縦のPDFを作り、ドライブの「請求書PDF」フォルダ（または指定したフォルダ）に保存
- 作成済みの行に「発行済み」とPDFのリンクを自動で記入するので、二重発行を防げる
- **インボイス制度に対応**：登録番号を記載し、10%と8%（軽減税率）の税率ごとに合計額と消費税額を表示（消費税の端数処理は税率ごとに1回）
- 選択した行の請求書だけを作り直すこともできる

## 導入手順（約5分）
1. Google スプレッドシートを新しく作る
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初から入っているコードをすべて消して、`Code.gs` の内容を貼り付けて保存する
4. スプレッドシートを再読み込みすると、メニューに「請求書」が追加される
5. 「請求書」→「① 初期設定（サンプル作成）」を実行する
   - 初回は Google の権限確認が出るので、自分のアカウントで許可する
6. 「設定」シートに、自社の会社名・住所・登録番号・振込先を入力する
7. 「請求書」→「② 未発行の請求書を作成」を実行する

## シートの構成
| シート | 内容 |
|---|---|
| 明細 | 請求番号・請求日・取引先・品目・数量・単価・税率を1行ずつ入力 |
| 設定 | 発行者の情報、保存先のフォルダID |
| 請求書テンプレート | 請求書のレイアウト（ここを編集すると見た目を変えられる） |

## カスタマイズ例（ご要望に応じて対応できます）
- 作成したPDFを、取引先へのメールの下書きに自動で添付する
- 毎月決まった日に自動で実行する（トリガー設定）
- 見積書・納品書にも対応する
- 自社のロゴ・印影を入れる
